# 验收范围与待验证项

2026-11-07，Windows10 / DSH0.2.2-rc.1 / Python3.12。alpha.8是公开发布整理，业务实现延续alpha.7。本机实验原件保留在开发机，不公开数据库、凭据、会话或原始实验目录。

| 范围 | 实际验证 | 边界 |
|---|---|---|
| 后端 | 57项Python、2项Node；采集→分析→回查→同发布日期原地更新的合成闭环、附件变化、重复提交、分析续跑、并发、超时worker、权限、人工覆盖、重启及备份恢复 | 受控合成数据；不等于实站确实发生改稿 |
| 实站 | 公开栏目4页40篇不同文章、2个分页响应；同一旧毕设通知采集两次、每次9个资源取得字节；原始对象SHA读回一致 | 两次正文相同；未亲历远端原地修改；不覆盖全部历史；长期无人值守仍待验证 |
| 网络 | 本机Python握手验证成功但HTTP403；默认验证证书的curl短期重复200，存在偶发握手失败；忽略个人curl配置后再次200 | 无法从客户端确定服务端策略或精确故障根因；未关闭TLS验证、未绕过登录或访问控制 |
| 原生宿主 | 非空固定合成会话页签位于轨迹右侧；9项页面检查，主题、430px、人工提案读回、服务启停；真实注册Agent上下文程序调用工具成功，缺身份和提升owner均拒绝 | 程序调用真实工具，不是模型自主验收 |
| Windows与包 | 数据/凭证私有ACL；拒绝无关目录；下载子进程退出保护；新Python缺依赖失败可见、修正后成功；独立目录从tgz安装、升级/重启读回、启动时停用工具/Skill消失 | 其他宿主版本、所有热卸载UI路径及目标机差异未验证 |
| Skill | 主Skill+references，格式有效，包含证据、幂等、租约、人工规则、来源和上线失败清单 | 真实模型按Skill自主完成查询→证据→整理→回执→回查→修改归档→恢复尚未执行，由用户决定上线联测 |

不自动修改项目计划，不共享SQLite给Workbench。Workbench联调另行实施。没有安装到日常环境、复制日常密钥或启用真实定时任务。

本仓库测试使用临时合成数据；执行方法见README。安装后的模型行为、语义准确率、真实聊天人工要求识别、长期采集和实际远端变化，必须在上线联测中单列结果，不能以Agent自报代替数据库读回。
