## 本机自检与恢复（2026-11-08 本机补丁）

“本机服务”中可使用“自检”和“检查并修复”。自检检查配置的 Python/jsonschema、目录归属、SQLite 只读 quick_check、凭据文件、服务实例应答、版本和采集器错误状态；不会执行 Service 初始化或数据库迁移。自检通过不代表消息语义或来源长期稳定性已验收。

插件加载时执行检查并尝试安全恢复；宿主存活期间每 30 秒检查连接。仅在明确连接被拒绝或端点文件缺失，且环境/数据库/凭据检查通过时尝试启动；Python 后端的目录文件锁继续防止并发写库实例。10 分钟内最多自动尝试启动 3 次；手动停止后当前插件生命周期内不自动拉起，手动启动或修复重新启用。

受限端口存在监听、实例身份不符、凭据缺失、已有目录丢失数据库、数据库损坏、非本插件目录均不自动覆盖或重建。不会自动安装依赖、更改 Windows 端口范围、杀未知进程或重放业务写操作。修复结果会复检并在本机服务区域显示；最近恢复状态仅保存在当前宿主内存。

本次已验证源码 73 项 Python、12 项 Node 测试，以及隔离 DSH 真实页面自检、停止后刷新、修复及独立 RPC 读回。日常安装文件已备份后更新，安装版 Controller 对日常数据自检通过；正在运行的 DSH 需重新加载插件/重启才能载入新入口和后台检查，不能等同于已完成日常窗口重载验收。
