# 验收范围与待验证项

2026-11-07，V0.2 / 0.1.0-alpha.9开发候选。目标Windows10、DSH0.2.2-rc.1、Python3.12。正式需求与逐项状态见开发仓库的 [V0.2收尾矩阵](acceptance/alpha.9.md)；实验原件不随包发布。

本轮验证需对应最终代码，不能复用alpha.7/alpha.8或中途65项通过作为结论。回归覆盖增量发现/显式回查分流、分析失败重启只重试分析、来源及附件更新、权限/租约/幂等/人工规则与恢复。页面在隔离DSH真实宿主操作后独立API读回；合成样例含三篇事件时间线、旧总结待复核、未知发布时间、暂不收录/重新纳入和整理重试。包需独立安装后再次检查依赖、工具/Skill、页面、重启和备份恢复。

来源长期稳定性、真实远端原地改稿、真实模型自主整理与语义准确率未通过本轮验收。此前有限院网采集结果只适用于当时环境，不扩大为本轮实站结论。内置浏览器桥不可用时使用独立临时浏览器，不读日常浏览器profile。

不自动修改项目计划，不共享SQLite给Workbench。本轮不安装日常DSH、不复制密钥、不创建真实任务。alpha.9是预发布试用候选；即使工程检查通过，也不代表真实模型联测或用户验收完成。
