# 消息雷达 v0.2.0

面向 Windows 10、DSH 0.2.2-rc.1、Python 3.12 的正式发布版本。通过聊天 Agent 管理关注、采集与整理通知、关联事件并安排选择性回查。

## 本版内容

- 持久原文/资源版本、去重校验、待整理队列、失败接续、暂不收录及事件时间线。
- 新通知增量发现与指定旧通知回查分离，正文/同链接附件变化保留依据。
- 发现周期、暂停及已有回查计划的页面设置；本人规则受保护。
- 本机自检和有限自动恢复：每30秒检查连接，10分钟最多尝试恢复3次，手动停止后不自动拉起。
- 避开 Fetch 受限端口；后端工作目录与插件安装目录分离，修复 Windows 升级替换卡住。
- Agent 功能索引和组合任务手册，明确参数查询、权限、租约、修订、回执和完成判据。
- 来源建设说明采用 Crawl4AI 引擎；引擎不随插件自动安装，当前院网适配器沿用现有传输。

## 验证

73项Python测试、13项Node集成测试、Skill格式与契约方法名/引用校验通过。v0.2.0实际tgz解包后在隔离DSH验证：Skill/工具发现、自检、停止后刷新、恢复并复检、频率与暂停设置、独立RPC读回、生命周期说明。合成数据验证不代替长期真实站点验收。

## 安装和升级

在 DSH 插件添加入口粘贴下方 tgz 资产的完整 URL；也可使用 `github:chanhaoxian5-ship-it/dsh-radar#v0.2.0`。配置独立 Python 和数据目录，安装 requirements.txt。升级前停止旧版后端并一致备份数据库及对象库；升级完成后重载/重启 DSH。不要混用旧后台与新插件，也不要只复制运行中的主数据库。旧版本及资产保留。

## 功能边界

采集程序不会自动调用模型：整理需要Agent会话接力。等待分析/执行器的活动运行可能阻挡同关注后续定时发现。调度按成功完成后的间隔顺延，不保证每天固定时刻。长期来源稳定性、所有回查表单组合及真实模型理解准确率未全面验收；永久删除、队列自动过期和自动模型调度桥未提供。
